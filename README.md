# ШартномаЁр — веб-сайт (лендинг + прототип кабинета юриста)

React 18 + TypeScript + Vite + Tailwind CSS v4.

## Запуск

```bash
npm install
npm run dev       # dev-сервер на http://localhost:5173
npm run build     # продакшн-сборка в dist/
npm run preview   # предпросмотр собранной версии
```

## Структура

- `/` — публичный маркетинговый лендинг о продукте
- `/app/login` — вход / регистрация (демо: любой email и пароль)
- `/app/dashboard` — дашборд юриста
- `/app/clients`, `/app/clients/:id` — клиенты
- `/app/cases`, `/app/cases/:id` — дела
- `/app/drafts/new` — мастер создания черновика договора (ИИ-сборка симулируется)
- `/app/drafts/:id` — редактор черновика: журнал версий, экспорт в .docx (реальная генерация файла через библиотеку `docx`) и в PDF (через печать браузера)
- `/app/templates` — библиотека шаблонов и пунктов договора
- `/app/alerts` — уведомления об изменениях законодательства
- `/app/settings` — профиль, лимит ИИ-запросов, журнал аудита

Данные — мок-данные, сохраняются в localStorage браузера (сброс — кнопка в Настройках).

Содержание и функциональность основаны на `ShartnomaYor_TRD.docx` (техническое требование к разработке).
